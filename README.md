# stat_phys
`stat_phys` is an early-stage Python library for performing statistical physics simulations.
Currently, the library contains a single module, `canonical`, which provides the `CanonicalMC` class, and is at version 0.1.0. 
The `CanonicalMC` class allows users to create simulations of physical systems within the canonical ensemble. Documentation 
for the library will be uploaded soon.
